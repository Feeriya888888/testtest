# Промышленный Пайплайн Аналитики и ML-Тарификации
               Take-Home Project

Комплексное производственное решение для регулярной пакетной очистки данных (ETL), аналитического моделирования (DWH) и предсказания логистических ставок за рейс (ML Batch Inference).

## 1. Архитектура Решения и Обоснование Стека
* **СУБД: PostgreSQL 17** — Выбран для слоя Core & Mart благодаря развитому аналитическому движку, нативной поддержке перцентилей (`PERCENTILE_CONT`) и оконных функций. Использование операторов `ON CONFLICT DO UPDATE` обеспечивает строгую транзакционную идемпотентность.
* **Оркестратор: Apache Airflow 2.10.x** — Промышленный стандарт управления направленными графами задач. Механизм `logical_date` гарантирует детерминированное выполнение и поддержку Backfill-запросов за прошлые периоды без дублирования.
* **ML-модель: LightGBM Regressor** — Эффективный градиентный бустинг, превосходящий классические линейные модели на разнородных табличных признаках. Отлично справляется с категориальными переменными высокой кардинальности (регионы отправления и назначения) и минимизирует RAM при скоринге.

## 3. Пошаговая Инструкция Запуска
1. Разверните контейнеры инфраструктуры:
   ```bash
   cp .env.example .env
   docker-compose up -d --build
   ```
2. Запуск backfill-обработки в Airflow за исторический период:
   ```bash
   docker exec -it dwh_airflow_scheduler airflow dags backfill -s 2026-10-01 -e 2026-10-26 etl_core_dwh_delivery_prices
   ```
3. Запуск регулярного ML Batch-скоринга:
   ```bash
   docker exec -it dwh_airflow_scheduler python /opt/airflow/ml/ml_pipeline_inference.py
   ```
